# Project 2: Employee Payroll and Deduction Analysis

## Problem Description
This project calculates an employee's gross salary using basic pay, allowances, overtime payment, and incentives. It applies progressive deductions and generates a formatted salary statement showing the net salary.

## Programming Language
Python

## Concepts Used
- Variables and data types
- Arithmetic operators
- Conditional statements (if, elif, else)
- User input and output
- Mathematical calculations

## Files Included
- `Question_02_Payroll.py` – Python source code
- `Screenshots/` – Code and output screenshots

## How to Run
1. Download the Python file.
2. Open it using Python or VS Code.
3. Run the program.
4. Enter the employee details when prompted.
5. View the generated salary statement.

## Conclusion
The program calculates gross salary, applies the specified progressive deductions, and displays the employee's final net salary in a formatted statement.
